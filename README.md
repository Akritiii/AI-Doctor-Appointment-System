# AI-Powered Doctor Appointment System

## Overview
A full-stack healthcare platform built using the MERN Stack (MongoDB, Express.js, React.js, Node.js) that enables patients to book appointments, manage healthcare interactions, and receive AI-powered symptom analysis.

## Features

### Patient Features
- User Registration & Authentication
- Browse Doctors by Specialization
- Book Appointments
- Cancel or Reschedule Appointments
- View Appointment History

### Doctor Features
- Manage Doctor Profile
- View Patient Appointments
- Update Availability
- Appointment Management Dashboard

### Admin Features
- Manage Doctors and Patients
- Monitor Appointments
- Platform Administration

### AI Symptom Analysis
- Describe symptoms in natural language
- AI analyzes symptoms using Gemini AI
- Suggests possible diseases and health conditions
- Recommends appropriate medical specializations
- Displays available doctors related to the predicted condition

### Smart Doctor Recommendation
- Suggests doctors based on:
  - Symptoms
  - Specialization
  - Availability
  - Consultation Fees

## Tech Stack

### Frontend
